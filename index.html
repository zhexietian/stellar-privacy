星际王朝 隐私政策

包名 com.dsh.stardynasty ｜ 生效日期 2026-10-27 ｜ 最后更新 2026-10-27

本隐私政策适用于移动游戏《星际王朝》（包名：com.dsh.stardynasty，以下简称「本游戏」）。 我们深知个人信息对你的重要性，并会尽力保护你的个人信息安全。请在使用本游戏前仔细阅读本政策。

一、我们收集哪些信息

1. 你主动提供的信息

本游戏没有账号系统，不需要注册、登录，也不收集你的姓名、手机号、身份证号、邮箱或通讯录。

游戏内的存档（舱段等级、星图进度、殖民地、舰队、成就等）默认保存在你的设备本地。 你可以通过游戏内的「导出」功能自行备份，备份内容由你自行保管。

2. 游戏运行中在本机产生的信息

  • 游戏进度与设置（本地存储）；
  • 崩溃与异常日志（仅保存在本机，我们不会主动上传）。

3. 通过第三方广告 SDK 收集的信息

本游戏接入 TapADN（Dirichlet Ad，由 TapTap 提供） 激励视频广告。 在你同意本政策并同意广告隐私授权后，该 SDK 可能收集：

信息类型用途
设备标识符（OAID、Android ID）广告投放、频次控制、反作弊
设备信息（机型、系统版本、屏幕参数、语言、时区）广告适配与兼容性判断
网络信息（网络类型、IP 地址、运营商）广告请求与区域合规
广告交互数据（曝光、点击、完成状态）广告计费与效果统计
我们不会通过该 SDK 收集你的通讯录、短信、相册、精确位置、麦克风或摄像头内容。 SDK 的隐私开关已按最小必要原则配置：位置、电话状态、MAC/BSSID/SSID、传感器、应用安装列表均关闭； OAID 与 Android ID 仅在获得授权后用于广告。

如果你拒绝广告隐私授权，本游戏不会初始化广告 SDK，你仍可正常游玩全部非广告内容， 只是无法使用「观看广告领取奖励」功能。

二、我们如何使用这些信息

  1. 向你展示激励视频广告，并在你完整观看后发放游戏内奖励；
  2. 统计广告效果、控制展示频次、识别无效流量与作弊行为；
  3. 排查广告加载失败等技术问题；
  4. 履行法律法规要求的合规义务。

我们不会将上述信息用于与你无关的用途，也不会出售你的个人信息。

三、信息的共享、转让与公开披露

除以下情形外，我们不会与任何第三方共享你的个人信息：

  1. 广告服务提供方：TapADN（Dirichlet Ad）为展示广告所必需的信息，按其隐私政策处理；
  2. 法律法规要求：依据法律法规、司法或行政机关的强制性要求；
  3. 你另行同意的情形。

我们不会转让你的个人信息，除非发生合并、分立等情形且要求承接方继续受本政策约束。我们不会公开披露你的个人信息。

四、信息的存储与保护

  1. 游戏存档保存在你的设备本地；卸载应用或清除应用数据会删除这些内容；
  2. 广告 SDK 所需的信息由广告服务方按其规则存储与处理，存储期限以其隐私政策为准；
  3. 我们采取合理的技术措施保护信息安全，但请理解：任何技术都无法保证绝对安全。

五、你的权利

  1. 撤回广告授权：进入游戏「记录 → 激励广告 → 个性化广告」可关闭个性化广告； 卸载重装或清除应用数据可重置全部授权状态；
  2. 删除本地数据：清除应用数据或在系统设置中卸载本游戏；
  3. 拒绝广告：不观看广告不影响核心玩法；
  4. 投诉与咨询：通过下方联系方式与我们联系。

六、未成年人保护

  1. 若你是未满 14 周岁的儿童，请在监护人陪同下阅读本政策，并在监护人同意后使用本游戏；
  2. 我们不会主动收集未成年人的个人信息，也不会向未成年人推送个性化广告；
  3. 监护人如发现未成年人未经同意使用本游戏或产生相关数据，可联系我们删除。
